# เว็บโชว์ผลงาน: ชิ้นงานกรองไอออนทองแดง (Cu²⁺)

ถ่านกัมมันต์กะลามะพร้าว + เยื่อกระดาษรีไซเคิล ขึ้นรูปเป็นก้อนชิ้นเดียว แสดงผลแบบ 3 มิติ 4 หน้า

1. ชิ้นงานในท่อน้ำทิ้ง (แอนิเมชันน้ำไหลผ่าน)
2. ชิ้นงานอย่างเดียว
3. แยกส่วนพร้อมคำอธิบายสั้น ๆ
4. ทดสอบการไหลของน้ำ — คลิกที่ชิ้นงานเพื่อแยกชั้น/รวมชั้น

ทุกหน้าลากเพื่อหมุน ซูมเข้า/ออก และกดปุ่มมุมขวาล่างเพื่อขยายเต็มจอได้
ลิงก์ตรงไปแต่ละหน้า: `#1` ถึง `#4`

## ขึ้น GitHub Pages
1. สร้าง repository ใหม่ แล้วอัปโหลด `index.html` และ `README.md`
2. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
3. รอสักครู่ จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

ไฟล์เดียว ไม่ต้อง build โหลด Three.js และฟอนต์จาก CDN จึงต้องมีอินเทอร์เน็ตตอนเปิดเว็บ
